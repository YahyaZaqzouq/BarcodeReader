# نظام الباركود — صيدلية معاذ

نظام فحص باركود يعمل كموقع على الإنترنت، ويتحدث تلقائياً كلما عدّلت ملف الإكسيل ورفعته.

## كيف تعمل التعديلات (طريقة يومية بسيطة)

1. افتح موقع GitHub وسجّل دخولك.
2. اذهب إلى الريبو (repo) بتاعك.
3. اضغط `Add file` ← `Upload files`.
4. اسحب ملف الإكسيل المعدل **بنفس الاسم** `data.xlsx` وارميه هناك (سيستبدل القديم).
5. اضغط `Commit changes` (اكتب أي كلمة زي "تعديل").
6. خلال دقيقة أو دقيقتين، الموقع يتحدث تلقائياً.

### رابط الموقع
بعد أول نشر، ادخل على:
`https://<username>.github.io/<repo-name>/`

## الإعداد الأول (مرة واحدة فقط)

### الخطوة 1: إنشاء الحساب والريبو
- اعمل حساب على [github.com](https://github.com) إن لم يكن لديك.
- اضغط `+` في أعلى يمين الصفحة ← `New repository`.
- الاسم: `barcode-system` (أو أي اسم).
- **نوع الريبو: `Public`** (GitHub Pages المجانية لا تشتغل إلا على الريبوهات العامة، ومفيش مشكلة من بياناتك لأنها أسماء أصناف فقط).
- اضغط `Create repository`.

### الخطوة 2: رفع الملفات
في صفحة الريبو الجديد (الفارغ) اضغط `uploading an existing file` أو `Add file` ← `Upload files` وارفع **هذه الملفات**:
- `data.xlsx`
- `convert.py`
- `template.html`
- `.github/workflows/build.yml`

ملاحظة: ملف `.github/workflows/build.yml` لا يمكن رفعه بالسحب والإفلات العادي (لأنه داخل مجلدات). اسأل المطوّر، أو ارفعه هكذا:
1. `Add file` ← `Create new file`
2. اكتب في خانة الاسم: `.github/workflows/build.yml`
3. الصق محتوى الملف (موجود في مجلد github-deploy على جهازك)
4. اضغط `Commit new file`
ثم ارفع باقي الملفات بالسحب والإفلات.

### الخطوة 3: تشغيل النشر التلقائي (GitHub Pages)
1. في الريبو، ادخل `Settings` ← `Pages` (من القائمة اليسرى).
2. في قسم **Build and deployment**, غير **Source** إلى `GitHub Actions`.
3. روح إلى تبويب `Actions` وشغّل الوركفلو `Build & Deploy` يدوياً (Run workflow) — أو اعمل أي تعديل صغير وCommit، وده هيشغّله تلقائياً.

### الخطوة 4: جرّب الموقع
افتح رابط الموقع: `https://<username>.github.io/<repo-name>/`

## ملفات المشروع

| الملف | الوظيفة |
|---|---|
| `data.xlsx` | ملف الأصناف (كود / باركود / اسم الصنف) — اللي تعدله وترفعه |
| `convert.py` | سكربت يحوّل الإكسيل إلى صفحة HTML |
| `template.html` | قالب التصميم (لا تحتاج تعديله) |
| `.github/workflows/build.yml` | مهمة أتمتة البناء والنشر |
| `index.html` | الصفحة النهائية الناتجة (يتولد تلقائياً) |

## ملاحظات
- العمود الأول = **الكود**، الثاني = **الباركود**، الثالث = **اسم الصنف**.
- الصف الأول في الإكسيل يعتبر عنواناً ولا يدخل في البيانات.
- إذا ظهرت مشكلة "خارج المدة" في النشر، روح لـ Actions وشغّله يدوياً مرة أخرى.
